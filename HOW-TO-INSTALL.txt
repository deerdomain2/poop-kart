POOP KART — INSTALLABLE APP
===========================

This folder is the whole app. It must be put on a website with an https:// address
before Chromebooks and iPads can install it. GitHub Pages does this for free.

1. PUT IT ON GITHUB PAGES (one time, ~5 minutes)
   a. Sign in at https://github.com (create a free account if needed).
   b. Click "+" (top right) > "New repository". Name it:  poop-kart
      Choose "Public", then "Create repository".
   c. On the new repo page click "uploading an existing file".
      Drag in EVERYTHING inside this folder (index.html, sw.js,
      manifest.webmanifest, .nojekyll and the icons folder) — not the folder itself.
      Tip: .nojekyll is hidden on Windows; it's optional, skip it if you can't see it.
      Click "Commit changes".
   d. Go to Settings > Pages. Under "Branch" pick "main" and "/ (root)", click Save.
   e. Wait about a minute. Your game is at:
         https://YOUR-GITHUB-NAME.github.io/poop-kart/

2. INSTALL ON A CHROMEBOOK
   Open that address in Chrome. Click the install icon at the right end of the
   address bar (a little monitor with a down arrow), or the three-dot menu >
   "Cast, save and share" > "Install page as app". It appears in the app launcher
   and can be pinned to the shelf.

3. INSTALL ON AN IPAD
   Open the address in Safari (must be Safari). Tap the Share button (square with
   an up arrow) > "Add to Home Screen" > Add. Launch it from the home screen icon.

4. NOTES
   - After the first launch the game works with no internet connection.
   - To update the game later, upload the new files to the same repository.
     Devices pick up the update the next time the app is opened (sometimes it
     takes two launches).
   - The 2-player ONLINE mode only works on the claude.ai page; the installed app
     is single player (keyboard, gamepad or touch).
   - Best times and found secrets are saved separately on each device.
